# Decisions

The initial schema/API freeze is recorded in [`initial-contract.md`](initial-contract.md). Add one focused file per consequential decision and list it in `memory/README.md`.

Each record should include the date, status, context, decision, reason, alternatives considered, consequences, and affected contracts or file paths. If a decision is revised, preserve the history and link to the replacement. Update `memory/structure/` for any corresponding implementation or schema change.
