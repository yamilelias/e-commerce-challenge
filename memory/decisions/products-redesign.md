# Products page editorial redesign

- Date: 2026-10-17
- Context: The homepage redesign was complete, while the catalog and detail routes still used basic commerce layouts. The user approved a Lovable-inspired photo hero, editorial cards and motion, alternate photos, a detail gallery, and contact banners, while retaining Field & Form's palette and working catalog/cart behavior.
- Chosen approach: Scope editorial styling to the products routes and their card variant. Reuse `Reveal`, the API client, URL-backed catalog controls, and `CartProvider`. Curate two Commons alternates per seeded SKU, retain primary image columns, add ordered alternate rows, and expose primary-first `images` alongside existing flat response fields. Add direct Commons background URLs and visible credits on both page banners.
- Reason: This keeps the homepage and admin write form stable while giving the public catalog and details richer imagery. Additive storage and response fields preserve existing consumers. Per-photo source, creator, and license metadata travel with the imagery.
- Alternatives considered: Replacing primary image fields would break current consumers; a new gallery package would add dependency and motion complexity; sourcing exact variants for all seed names was not feasible, so relevant representative product photos are used where needed.
- Consequences: Remote photos may fail independently and are covered by local color/primary image fallbacks. The seed import owns alternate curation; admin product editing does not manage alternates. Some fixture products have representative category imagery rather than literal products. See `docs/qa/products-redesign.md` for verification results and limits.
