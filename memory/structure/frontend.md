# Frontend foundation and catalog (FE-01)

- UI routes: `/` in `apps/web/src/app/page.tsx` composes `HomeHero` and `HomeSections` in that order. `HomeSections` fetches up to eight real products and available categories through the existing browser API client, then renders `#collections`, `#featured`, and `#story`. See the focused redesign structure records. `/products` in `apps/web/src/app/products/page.tsx` and `CatalogPageClient.tsx` renders URL-backed search, category, sort, and pagination controls.
- The shared shell is `apps/web/src/app/layout.tsx`; colors and daisyUI theme are in `apps/web/src/app/globals.css`. `StoreHeader.tsx` retains the brand/Shop/Cart links and adds the homepage section links, sticky state, and mobile dialog. Product cards in `apps/web/src/components/products/ProductCard.tsx` show remote product photos, stock status, and integer-cent USD prices. `apps/web/src/components/products/ProductImage.tsx` loads HTTPS URLs directly with a fixed-size crop and restores the deterministic category-initial placeholder when the URL is missing or fails.
- `apps/web/src/components/catalog/CatalogResults.tsx` fetches `/api/v1/products` with abortable requests and renders loading, empty, retryable error, and result states on the catalog route. The homepage now uses `apps/web/src/components/home/sections/HomeSections.tsx` to fetch `/api/v1/products` and `/api/v1/categories` once each; `CategoryLinks.tsx` remains in the codebase but is no longer mounted on `/`.
- Browser API functions, contract shapes, and error mapping live in `apps/web/src/lib/api/client.ts` and `types.ts`. They call same-origin routes. `apps/web/src/app/api/v1/[...path]/route.ts` forwards GET, POST, PATCH, DELETE to server-only `API_INTERNAL_URL`, preserving selected request headers, upstream status/body, and every `Set-Cookie` value.
- `apps/web/package.json` and lockfile pin Next.js, React, TypeScript, Tailwind CSS, and daisyUI. `next.config.ts` emits standalone output for the DevOps-owned Dockerfile. Local checks: `npm run typecheck`, `npm run lint`, `npm run build`.
- `/products/[id]` in `apps/web/src/app/products/[id]/page.tsx` and `ProductDetail.tsx` reads `/api/v1/products/{id}` and shows description, weight, stock, add-to-cart, and photo creator/source/license links. `/cart` in `apps/web/src/app/cart/CartPageClient.tsx` reads current product details for availability, estimated totals, and photos. The `Product` response shape in `apps/web/src/lib/api/types.ts` includes nullable image URL, source, creator, and license fields.
- `apps/web/src/features/cart/CartProvider.tsx`, `storage.ts`, and `useCartProducts.ts` own persistent, validated ID/quantity-only cart state. `apps/web/src/components/layout/StoreHeader.tsx` shows its count.
- `/checkout` in `apps/web/src/app/checkout/CheckoutPageClient.tsx` submits `/api/v1/orders` with a stable UUID. `apps/web/src/features/checkout/attempt.ts` retains its normalized original body, fingerprint, and key in sessionStorage for retry and refresh. An unresolved attempt can only be replayed with the original body/key or explicitly reset; only confirmed paid responses clear the cart and navigate to the receipt.
- `/orders/[reference]` in `apps/web/src/app/orders/[reference]/page.tsx` and `ReceiptPageClient.tsx` reads `/api/v1/orders/{reference}?token=...`, displays server snapshots, and handles missing/wrong tokens neutrally. `apps/web/next.config.ts` sets no-store, no-referrer, and noindex response headers. `apps/web/src/lib/api/client.ts` and `types.ts` define the purchase calls and frozen DTOs.
- `apps/web/src/app/api/v1/[...path]/route.ts` also forwards the safe same-origin `Location: /api/v1/products/{id}` from product creation.
- `/admin/login`, `/admin/products`, `/admin/products/new`, `/admin/products/[id]/edit`, and `/admin/import` are implemented in `apps/web/src/app/admin/**`. `apps/web/src/features/admin/AdminSessionProvider.tsx` bootstraps Symfony session and CSRF, rotates in-memory CSRF after login, handles logout, and maps 401/403 to redirect or manual retry. `AdminShell.tsx` gates protected routes and provides navigation.
- `apps/web/src/app/admin/products/AdminProductsClient.tsx` reads filtered, paged `/api/v1/admin/products`, confirms soft-delete, and refreshes the list. `apps/web/src/features/admin/ProductFormClient.tsx` creates/edits through protected JSON endpoints, converts cents to a decimal edit string, and displays field errors. `apps/web/src/app/admin/import/page.tsx` sends one FormData `file` to `/api/v1/products/import` and renders summary counts and row issues. Admin API calls and DTOs are in `apps/web/src/lib/api/client.ts` and `types.ts`.
- Remote photos depend on the curated HTTPS URLs remaining available; products without a working URL show the placeholder.
- The shared `apps/web/src/app/layout.tsx` main landmark has `id="main-content"` for the homepage redesign's skip-link target. Shared homepage motion duration/easing variables are declared in `apps/web/src/app/globals.css`; redesign sections are still in progress.
