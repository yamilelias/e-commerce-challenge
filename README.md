# E-Commerce Challenge

A weekend-scoped MVP specification for a Next.js + Symfony + SQLite e-commerce application, running in separate Docker containers.

## Project status

Planning specifications and challenge assets only. The actual application, Dockerfiles, and running setup have **not** been implemented yet.

## Orchestrator bootstrap

1. Read `docs/00-ORCHESTRATOR.md` and `docs/01-PRODUCT.md`.
2. Read `docs/02-ARCHITECTURE.md` and `docs/04-API.md` before freezing shared contracts.
3. Delegate work according to `docs/03-BACKEND.md`, `docs/05-FRONTEND.md`, `docs/06-INFRASTRUCTURE.md`, and `docs/07-QUALITY.md`.
4. Use `data/products.csv` as the supplied fixture and `docs/reference/landing-page.png` as the visual reference.
5. Replace this planning README with verified build, test, and local setup instructions during Phase 6.
